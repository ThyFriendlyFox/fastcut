# FastCut

Video editing for everyone: pick a template, drag clips into the boxes, export.

- Runs entirely in the browser — clips never leave your computer.
- 12 templates (wide, tall, square), captions, background color, rounded corners, background music, per-box sound/crop/start time.
- Exports MP4 (Chrome, Edge, Safari) or WebM, recorded in real time from the preview.

```bash
npm install
npm run dev
```

Deploys to Vercel as a static Vite site (`vercel.json`).
